# Обзор проекта tia-text-sync

## Контекст

Командная разработка PLC-проектов в Siemens TIA Portal страдает от отсутствия нормального version control. Проекты хранятся в форматах, где diff почти нечитаем, а merge невозможен без специального инструментария.

## Цель

Создать инструмент, который:

- подключается к запущенному TIA Portal через **Openness API**
- экспортирует содержимое проекта в текстовое, нормализованное представление
- раскладывает экспорт в файловую структуру, пригодную для Git
- позволяет командам делать code review изменений в логике ПЛК
- поддерживает обратный импорт изменений в существующий проект

## Scope

| Этап | Описание | Статус |
| ---- | -------- | ------ |
| 1 | Запуск TIA Portal / подключение к работающему процессу | ✅ Done |
| 2 | Открытие проекта, отображение дерева устройств и блоков | ✅ Done |
| 3 | Экспорт по дереву проекта: блоки → `blocks/`, теги → `tags/`, UDT → `types/` | ✅ Done |
| 4 | Нормализация XML (удаление нестабильных полей, стабильный diff) | ✅ Done |
| 5 | Экспорт HW-конфигурации устройств → `hw.xml` | ✅ Done |
| 6 | WinForms GUI: подключение, дерево проекта, выбор рабочей папки, экспорт | ✅ Done |
| 7 | Импорт: исходники → `GenerateBlocksFromSource`, XML-блоки → `PlcBlockComposition.Import`, `tags/` → `PlcTagTableComposition.Import` | 📋 Planned |

## Рабочая папка (workspace)

Приложение привязывается к корневой папке Git-репозитория:

- Путь сохраняется между запусками (`%AppData%\TiaTextSync\workspace.txt`)
- Экспорт записывает файлы напрямую в рабочую папку — без лишних диалогов
- В будущем: импорт читает изменения из этой же папки

## Структура экспорта

```text
<workspace>/                    ← корень Git-репозитория
  <DeviceName>/                 ← устройство (символы "/" в имени заменяются)
    hw.xml                      ← снимок HW-конфигурации (только для git diff)
    <PlcName>/
      blocks/                   ← блоки, подпапки повторяют группы проекта TIA
        Main.scl                ← SCL
        Motors/
          Motor_FB.scl
          Motor_DB.db           ← DB
          Conveyor.awl          ← STL
          Conveyor_LAD.xml      ← LAD, FBD, GRAPH, F-блоки
          Conveyor_LAD.lad      ← текстовый вид LAD/FBD для чтения и diff, не импортируется
      tags/                     ← таблицы тегов в SimaticML XML, с группами проекта
        Main_Tags.xml
      types/                    ← UDT, с группами проекта
        MotorType.scl
      tech/                     ← технологические объекты в SimaticML XML, с группами проекта
        Axis_1.xml
        PID_Compact_1.db        ← исходник DB, если TIA не поддерживает XML для объекта
```

## Round-trip

Обратная запись изменений в TIA Portal планируется для `blocks/`, `tags/`, `types/`:

```text
Изменения в Git → tia-text-sync import → TIA Portal
```

Файл `hw.xml` — только для отслеживания изменений в Git; применяется вручную через TIA Portal GUI.

## Ограничения

- Работает только на машине с установленным TIA Portal (Windows, x64)
- Требует членства пользователя в группе `Siemens TIA Openness`
- Использует API версии V21 и работает только с TIA Portal V21, установленным в папку по умолчанию
- HW-конфигурация экспортируется для diff, но автоматический импорт не поддерживается

## Что НЕ входит в scope (сейчас)

- Автоматический merge конфликтов при параллельных изменениях
- Поддержка HMI WinCC (только PLC-часть)
- Построение проекта с нуля из файлов (только обновление существующего)
