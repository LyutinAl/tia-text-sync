# ADR 001: Использование Siemens TIA Openness API

**Статус:** Принято

**Дата:** 2026-03-09

## Контекст

Для доступа к данным TIA Portal проекта программным способом существует несколько вариантов:

1. Прямое чтение файлов проекта (`.ap17` — ZIP-архив с XML)
2. Использование официального Openness API
3. Эмуляция действий пользователя (UI automation)

## Решение

Использовать официальный **Siemens TIA Openness API** (`Siemens.Engineering.dll`).

## Обоснование

- Официальный API — единственный поддерживаемый Siemens способ программного доступа
- Предоставляет стабильную объектную модель: проект → ПЛК → группы блоков → блоки
- Поддерживает экспорт блоков в XML и генерацию SCL-исходника
- Формат внутренних файлов `.ap17` не документирован и может меняться между версиями TIA

## Последствия

- Приложение должно работать только на машине с установленным TIA Portal
- Целевой пользователь должен состоять в группе `Siemens TIA Openness` (настраивается в TIA Portal Options)
- Зависимость от версии TIA Portal: dll берётся из конкретной установки (V17)
- Только Windows, только x64
